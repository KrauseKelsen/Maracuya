# Referencias para la arquitectura XML–Compose

Fecha de consulta: 20 de octubre de 2026.

Esta carpeta reúne fuentes gratuitas para estudiar cómo construir una biblioteca Android de componentes configurable desde XML.

## Documentos

1. [Bases y buscadores científicos](01-bases-cientificas.md): dónde localizar investigación de ingeniería de software y cómo distinguir acceso al índice de acceso al artículo.
2. [Sistemas de diseño y arquitectura Android XML](02-design-systems-android-xml.md): implementaciones oficiales, documentación y mecanismos relevantes para Maracuya.
3. [Fundamentos de la propuesta](03-fundamentos-propuesta.md): papers, informe técnico y contratos Android utilizados para justificar la separación de responsabilidades, capacidades y estados.

## Alcance de esta recopilación

Las bases científicas son puntos de búsqueda. Las referencias de Material, Backpack y Fluent son evidencia técnica primaria de sus implementaciones; no se presentan como artículos científicos revisados por pares.

Esta es una selección inicial de fuentes, no una revisión sistemática ni una validación experimental de una arquitectura. Las inferencias para Maracuya aparecen identificadas como propuestas de estudio.

Se priorizaron documentación oficial y repositorios de sus autores, con evidencia explícita de Android Views/XML. Una biblioteca exclusivamente Compose no se considera evidencia de una arquitectura XML.

Los enlaces a ramas `main` y `master` pueden cambiar. Antes de adoptar una implementación concreta se deberá registrar el commit o release estudiado.
